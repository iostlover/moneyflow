# 💴 日本の資金の流れ可視化ダッシュボード (Money Flow Analyzer)

日本の公共データ（政治資金収支報告書・政府調達情報）をネットワークグラフとしてインタラクティブに可視化するプロトタイプシステムです。  
省庁・政治家・企業間の資金の流れを3Dグラフで直感的に探索できます。

## 🗺️ グラフの見方（ノードの色）

| 色 | 種類 | 説明 |
|---|---|---|
| 🟡 **金色** | 日本銀行（資金の根本） | 全資金の起点。クリックすると各省庁への予算配分が確認できます |
| 🔴 **赤** | 政府機関（省・庁・府） | 財務省・防衛省・デジタル庁などの省庁 |
| 🔵 **シアン** | 企業（一般調達の受注先） | 政府調達契約を受注した一般企業 |
| 💙 **青** | 政治家・関連団体 | 政治資金収支報告書に登場する政治家・政治団体 |
| 🟢 **緑** | 献金者（個人・企業） | 政治家・団体への献金者 |
| 🟠 **オレンジ** | 政治活動の支出先 | 政治資金の支出先（業者など） |

## 🔍 使い方

1. **ノードをクリック** → 右パネルに関連する取引履歴が表示されます
2. **ドラッグ** → 3D空間を自由に回転・移動
3. **スクロール** → ズームイン・アウト
4. **検索ボックス** → 企業名・官公庁名で検索してジャンプ
5. **左パネル** → 国家予算のマクロデータを概観

## ⚡ 機能

- 🌐 **3Dインタラクティブ・ネットワークグラフ**（Three.js / react-force-graph-3d）
- 🏛 省庁・政治家・企業間の資金の流れを可視化
- 🔍 ノード名による検索機能
- 📊 国家予算マクロデータとミクロデータの統合表示
- 📅 取引日付・金額・名目の詳細表示

## 📂 データ出典

- 政府調達情報（令和5〜6年度概算）
- 総務省 政治資金収支報告書（令和4年分〜最新）
- e-Stat / data.go.jp 等の政府オープンデータ

> ⚠️ 本プロジェクトのデータの一部はシミュレーション・推計値を含みます。実際の数値は各省庁の公式資料をご参照ください。
